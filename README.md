# AI Quality Engineering

A hands-on portfolio exploring Quality Engineering for
AI/ML and Generative AI systems.

This repository documents my journey from traditional
Software Quality Engineering into AI Quality Engineering,
with a focus on testing, validation, reliability, and
observability of AI-powered systems.

## What I'm exploring

- AI-assisted test engineering
- Generative AI testing
- LLM response validation
- Prompt and evaluation testing
- RAG testing
- AI API testing
- Model output validation
- Hallucination detection
- Reliability and regression testing
- Performance and latency testing for AI services
- Responsible AI and safety validation
- AI quality gates in CI/CD
